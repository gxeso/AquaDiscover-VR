# 🐠 AquaDiscover — Immersive VR Aquarium

**An interactive virtual reality aquarium experience built with Unity and XR Interaction Toolkit.**

AquaDiscover is an educational VR application that allows users to explore an underwater environment, discover marine species, interact with aquatic life, and complete engaging missions through immersive gameplay.

## 🌊 Key Features

- **Immersive Aquarium Exploration** — Explore a virtual aquarium with interactive exhibits and underwater environments.
- **Marine Life Discovery** — Discover different aquatic species and inspect interactive fish specimens.
- **Fish Feeding Minigame** — Feed marine animals by interacting with food pellets.
- **Ocean Cleanup Mission** — Collect litter and help keep the aquarium environment clean.
- **Interactive Marine Quiz** — Test your knowledge of marine life through an educational quiz.
- **Mission Progression System** — Track discoveries, feeding activities, and cleanup objectives.
- **VR Locomotion** — Navigate exhibits using teleportation and snap turning.
- **Audio and Visual Feedback** — Experience sound effects, environmental visuals, and mission completion feedback.
- **Desktop VR Simulation** — Test interactions without a physical VR headset using Unity's XR Interaction Simulator.

## 🎮 Gameplay Objectives

Players can complete three main aquarium missions:

1. **Marine Discovery** — Discover and inspect marine species.
2. **Fish Feeding** — Feed aquatic animals to complete the feeding objective.
3. **Ocean Cleanup** — Collect litter from the aquarium environment.

Completing the required objectives contributes to the overall mission progression and victory experience.

An additional interactive quiz reinforces marine-life knowledge.

## 🚀 Getting Started

### Requirements

- Unity 6.3 LTS (6000.3.3f1)
- Unity Hub
- XR Interaction Toolkit and OpenXR packages
- Compatible VR headset for headset-based gameplay, or XR Interaction Simulator for desktop testing

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gxeso/AquaDiscover-VR.git
   ```

2. Open Unity Hub.
3. Select **Add project from disk**.
4. Choose the cloned `AquaDiscover-VR` folder.
5. Allow Unity to import assets and restore packages.
6. Open `Assets/Scenes/MainMenu.unity`.
7. Press **Play** to test the experience with the configured XR simulator, or configure a compatible VR headset.
